# 📊 Draw.io Data Flow Diagrams (DFD) — JAROOS

This folder contains the complete, editable Draw.io diagram code for **DFD Level 0** and **DFD Level 1**.

## 📁 Files Included:
- **`dfd0.txt`** — Draw.io XML code for **DFD Level 0 (Context Level Diagram)**.
- **`dfd1.txt`** — Draw.io XML code for **DFD Level 1 (Functional Process Decomposition)**.
- **`dfd0.drawio`** & **`dfd1.drawio`** — Pre-configured native Draw.io files for one-click opening.

---

## 🚀 How to Open in Draw.io (diagrams.net)

### Method 1: Open Directly (Fastest)
1. Go to [https://app.diagrams.net](https://app.diagrams.net) in any web browser.
2. Click **Open Existing Diagram** (or **File > Open From > Device...**).
3. Select `dfd0.txt` (or `dfd1.txt`).
4. The diagram will render on the canvas.

### Method 2: Copy & Paste XML
1. Open [https://app.diagrams.net](https://app.diagrams.net) and create a **Blank Diagram**.
2. Click on the top menu bar: **Extras > Edit Diagram...**
3. Select all text in the box and replace it with the text from `dfd0.txt` (or `dfd1.txt`).
4. Click **OK**.
5. The complete visual diagram with shapes, colors, and arrows will load immediately.
